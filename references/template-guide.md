# Outline Templates

These templates provide section order and paragraph responsibilities without assuming a research object, method, equation, or experimental outcome.

| Section | Guide |
| --- | --- |
| Abstract | [Guide](../subskills/abstract/references/template-guide.md) |
| Introduction | [Guide](../subskills/introduction/references/template-guide.md) |
| Problem Definition and Analysis | [Guide](../subskills/problem-definition/references/template-guide.md) |
| Methodology | [Guide](../subskills/methodology/references/template-guide.md) |
| Results and Discussions | [Guide](../subskills/results-and-discussions/references/template-guide.md) |
| Conclusion | [Guide](../subskills/conclusion/references/template-guide.md) |
| Citation | [Guide](../subskills/citation/references/template-guide.md) |

Add, merge, or remove paragraphs according to the study. Slots identify responsibilities, not sentences to copy verbatim. The corresponding `SKILL.md` supplies the writing rules.

The `.tex` files are section snippets, not typesetting templates. Load the [placeholder macro](../assets/templates/template-macros.tex) before previewing. Replace every `\slot{...}` before using a snippet in the manuscript.
